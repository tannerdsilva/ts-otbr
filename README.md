# ts-otbr

a forked concept of the homeassistant otbr app.

exploring opportunities to improve the multi-br operation of the appl.

## Installation

Add this repository to Home Assistant, then add the app.

[![Open your Home Assistant instance and show the add app repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Ftannerdsilva%2Fts-otbr)
[![Open your Home Assistant instance and show the dashboard of an app.](https://my.home-assistant.io/badges/supervisor_addon.svg)](https://my.home-assistant.io/redirect/supervisor_addon/?addon=tanners_openthread_border_router&repository_url=https%3A%2F%2Fgithub.com%2Ftannerdsilva%2Fts-otbr)

To add the repository manually, go to **Settings → Apps → App store → ⋮ → Repositories** and use: 

```txt
https://github.com/tannerdsilva/ts-otbr
```
